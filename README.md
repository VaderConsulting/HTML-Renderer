# HTML Renderer

VS 2010 C# working copy of HTML Renderer 1.4.4.0: a 100% managed .NET 2.0 library that paints HTML/CSS in WinForms without WebBrowser/MSHTML. `HtmlRenderer` (Library) exposes HtmlPanel, HtmlLabel, HtmlToolTip, HtmlContainer, and HtmlRender; `HtmlRenderer.Demo` (WinExe HtmlRendererDemo) runs DemoForm (sample tree, live HTML editor, HtmlPanel, optional IE WebBrowser compare) with PerfForm commented out in Program.Main. Samples cover intro, tables, images, links, HtmlPanel/Label/ToolTip/Render/Container; About.htm records CodePlex, New BSD, and authors Arthur Teplitzki (2012) and José Manuel Menéndez Poo (2009). Open `HtmlRenderer.sln`. This tree is a working copy of third-party source kept in Dave Robinson's Historical Dev archive.
